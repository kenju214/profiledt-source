Hướng dẫn Profile cho người mới (chỉ 5 phút)

1. Xem thử: Nháy đúp file index.html trong thư mục này.

2. Sửa thông tin: Chỉ sửa duy nhất file config.js bằng Notepad. Tìm các dòng có chữ THAY Ở ĐÂY.

Bước 1 — Điền Discord ID

  1. Mở Discord → Cài đặt → Nâng cao → bật Chế độ nhà phát triển.
  2. Chuột phải vào tên bạn → Sao chép ID.
  3. Trong config.js sửa: discordId: "DÁN_ID_VÀO_ĐÂY"
  4. Bắt buộc để hiện online: vào discord.gg/lanyard → gõ /setup → Enter.

Bước 2 — Tên, ảnh, link

  • name, bio, location: sửa chữ trong ngoặc kép.
  • Ảnh: chép file avatar.jpg vào chung thư mục, sửa avatar: "avatar.jpg".
  • Banner có sẵn: banner_executive.jpg, profile_banner.jpg, profile_banner_cyber.jpg.
  • socials: thay link Facebook/Instagram/TikTok của bạn. Xóa dòng là mất nút, copy dòng là thêm nút.
  • Server Discord: lấy link Mời trong server → dán vào inviteUrl.
  • Nhạc: chép file .mp3 vào thư mục → sửa url: "ten-file.mp3".

Lưu file (Ctrl+S) → mở lại index.html → bấm Ctrl+F5 nếu chưa thấy đổi.

Bước 3 — Đưa lên mạng

  1. Dễ nhất (30 giây): vào app.netlify.com/drop → kéo thả cả thư mục này vào → lấy link.
  2. Vercel: vào vercel.com → Add New → Upload thư mục → Deploy.
  3. Hosting cPanel: vào File Manager → public_html → Upload toàn bộ file bên trong thư mục này.
Về Discord: source này đã xóa sạch ID cá nhân của chủ cũ. Ô Discord để trống để bạn tự điền. ID Discord là công khai, không phải mật khẩu/token nên an toàn. Không bao giờ dán token Discord vào đây.

Lỗi hay gặp: không hiện online = chưa gõ /setup. Nhạc không kêu = bấm vào màn hình 1 cái. Sửa không thấy đổi = Ctrl+F5.
